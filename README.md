# 🦀 RustyShell (meme shell)

Welcome to **RustyShell**! This is a simple, fun, and fast terminal shell written in Rust. It's designed to be easy to use, even if you're just starting out with coding or custom shells.

## ✨ Features

- **Personalized Profile**: Set your name, age, and even your "bro/sis" status!
- **Cool Themes**: Choose from themes like `ocean`, `neon`, `forest`, `night`, and etc.
- **Meme Commands**: 
  - `teleport`: Jump between folders (like `cd`).
  - `vanish`: Clear your screen (like `cls`).
  - `matrix`: Enter the digital rain (Ctrl+C to exit).
  - `brohelp`: Get a list of everything you can do.
- **Smart Aliases**: It knows you're on Windows or Linux and helps you out (like turning `ls` into `dir` for Babe).
- **Animations**: Watch the shell load up with some cool shaking and loading effects (it says "Meme started"!).

##  How to Get Started

### 1. Prerequisites
You need to have **Rust** installed on your computer. If you don't have it, go to [rustup.rs](https://rustup.rs/) and follow the steps there.
or
you can download the .exe file from the [release](https://github.com/cyberworrier8088/RustyShell/releases/download/demo/RustyShell.exe) page. run in windows.

### 2. Run it!
Open your terminal in the project folder and type its:
```bash
cargo run
```

### 3. First Time Setup
The first time you run RustyShell, it will ask for your name, age, and theme choice. Don't worry, it remembers you for next time!

##  Commands you can use

- `help` / `brohelp` - Shows you the command menu.
- `whoami` - Reminds you who you are.
- `config` - Shows your saved profile details.
- `pwd` - Shows you exactly where you are in your files.
- `teleport <path>` - Moves you to a different folder.
- `time` - Tells you the current system time.
- `matrix` - Just for fun! See the green code falling.
- `exit` - Close the shell safely.
